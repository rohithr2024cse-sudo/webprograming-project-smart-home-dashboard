# Nestify — Smart Home Control Dashboard

A responsive smart-home dashboard built with **HTML, CSS and vanilla JavaScript**. No framework or build tools are required.

## Features
- Responsive desktop and mobile layout
- Device power toggles for lights, air conditioner, desk lamp and security camera
- Adjustable light brightness and AC temperature
- Home, Focus, Relax and Away scene presets
- Light/dark theme switch
- Live date and clock
- Energy overview and room cards

> **Note:** This is a front-end demo. Controls update the interface only; they do not connect to physical smart-home devices. Real device control requires a backend and compatible device APIs.

## Run locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Sign in at https://github.com/new and create a repository named `smart-home-dashboard`.
2. Choose **Public** (or use a private repo if your Pages plan/settings support it). Do not initialize with a README if you plan to upload these files together.
3. In the new repository, choose **Add file → Upload files**.
4. Upload `index.html`, `style.css`, `script.js`, and `README.md` from this folder into the repository root (not inside another folder).
5. Click **Commit changes**.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, select **Deploy from a branch**.
8. Select branch **main** and folder **/(root)**, then click **Save**.
9. Wait a few minutes. The published site URL will appear in the Pages section, typically `https://YOUR-USERNAME.github.io/smart-home-dashboard/`.

## Customize
- Change labels and device cards in `index.html`.
- Change colors, layout and responsive rules in `style.css`.
- Change device behavior and scene presets in `script.js`.
